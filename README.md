# 立体图形特训 · 行测空间推理专项攻克

一个**零依赖、纯前端、可离线**的行测「立体图形推理」专项训练应用。
淡粉色 iOS 风格界面，覆盖**六大题型**、**17 个通用秒杀方法**、**可交互 3D 实验室**、**错题自动归纳 + 薄弱点诊断 + 学习路径推荐**，并支持**题库实时更新与自动录入**。

---

## 一、快速开始

```bash
cd /workspace
python3 -m http.server 8899
# 浏览器打开 http://localhost:8899
```

或用任意静态服务器（Nginx / `npx serve` / VSCode Live Server）指向本目录即可。

> 手机使用：把整个目录部署到任意静态托管（GitHub Pages / 对象存储 / 内网），用手机浏览器打开 → 添加到主屏幕，即获得接近原生 App 的体验（已内置 PWA `manifest.json` 与 Service Worker 离线缓存）。

## 二、六大题型（生成器引擎）

| 题型 | 说明 | 核心方法 |
| --- | --- | --- |
| `fold` 折纸盒 | 给平面展开图，选出能折成的立体图形 | 相对面排除、箭头法、时针法、公共边/公共点 |
| `unfold` 拆纸盒 | 给立体图形，选出它的展开图 | 橡皮法、11 种展开图穷举、凹凸一致 |
| `view3` 三视图 | 给立体图形，选主视/俯视/左视 | 分层计数、遮挡原则、视图还原 |
| `section` 截面图 | 给立体图形与切法，选出截面形状 | 一刀切原则、基础体截面、平行面平行线 |
| `stack` 堆积拼合 | 小方块堆积、立体拼合与还原 | 分层计数、凹凸一致、特征点定位 |
| `rotate` 空间旋转 | 立体图形旋转后识别 | 特征锚点、镜像排除、轴向锁定 |

**答案正确性如何保证？**
题目不是人工"写"出来的，而是由**几何引擎按模型生成**的：折叠由「立方体在网格上滚动留印记」的可逆模型计算，三视图/截面由体素（voxel）投影与平面-多边形求交计算，答案索引由模型直接给出；干扰项通过定向变异 + 去重生成。因此**不存在手写答案出错**的可能。

已做批量校验：6 题型 × 3 难度 × 多种子共 **1080 道题**，全部满足「4 个互不相同的选项 + 有效答案 + 完整解析」，0 异常。

## 三、17 个通用解题方法（本应用的核心）

`relative` 相对面排除 · `arrow` 单面箭头法 · `arrow2` 双面箭头法 · `clock` 时针法 · `publicEdge` 公共边法 · `publicPoint` 公共点法 · `rubber` 橡皮法 · `view` 三视图原则 · `occlusion` 遮挡计数 · `section` 截面判定 · `onecut` 一刀切原则 · `stack` 拼合凹凸一致 · `concave` 凹凸匹配 · `count` 分层计数 · `rotate` 旋转锚点 · `feature` 特征定位 · `net11` 11 种展开图

每个方法包含：**适用场景 / 分步操作 / 口诀 / 常见陷阱 / 内置演示**，可一键「就练这类」直接刷题巩固。

**六阶段学习路径**（按你的诊断结果自动推荐该走哪一段）：

1. 第 1 阶段 · 建立空间直觉
2. 第 2 阶段 · 掌握核心三板斧
3. 第 3 阶段 · 攻克高频变形
4. 第 4 阶段 · 三视图与截面
5. 第 5 阶段 · 堆积、拼合与旋转

另有 **10 类高频失分原因**（PITFALLS）与对应补救方法，在「错题」页按你的实际错题自动匹配。

## 四、3D 实验室（动手练，比刷题更能建立直觉）

- **折纸盒实验室**：11 种经典展开图任选 → 拖动进度条 **0%→100% 连续折叠/拆解动画** → 可 360° 拖拽旋转观察 → 支持更换面上的图案（含方向性图案，用于练箭头法）。
- **堆积/截面实验室**：3×3 网格逐格调高度（0–4）搭建立体，三种模式即时联动
  - 搭建立体（3D 视图）
  - 三视图（主/俯/左同步显示）
  - 截面图（8 种预设切面 + 实时切割，附「一刀切」提示）
- 支持一键随机、清空、示例。

## 五、错题自动归纳 + 薄弱点诊断

- 每次作答自动记录：题目、你的选择、正确与否、耗时、所用方法、日期。
- **艾宾浩斯复习队列**（1 / 2 / 4 / 7 / 15 / 30 天），到期自动进入「今日复习」。
- 诊断引擎输出：
  - 六大题型正确率环形图 / 雷达图 / 14 天趋势
  - **薄弱题型**（正确率 < 66% 且样本 ≥ 4）
  - **薄弱方法**（错 ≥ 3 次的方法，直接反查是哪个技巧没掌握）
  - **学习建议**：自动生成下一步该练什么、练多久、用哪个方法
- 错题本支持：重做、标记已掌握、写笔记、按题型/方法筛选。

## 六、题库实时更新与自动录入（三种方式）

1. **订阅源自动同步**：在「我的 → 题库更新中心」填入一个题目包 URL（JSON 格式），每次打开应用自动拉取、去重后并入题库。已在 `data/questions-pack.json` 提供示例包（6 题，含 SVG 图形）。
2. **手动录入**：支持文字题干 / 上传 SVG / 上传图片，填写选项、答案、解析、适用方法、来源，存入本地题库并参与练习与统计。
3. **JSON 批量导入**：粘贴或选择 JSON 文件导入整套题包。

数据导出/导入：`localStorage` 全量备份为 JSON，换机不丢进度。

## 八、技术亮点

- **零依赖**：不引入任何第三方库，3D 投影、折叠变换、截面求交全部自研，代码可控、离线可用、秒开。
- **数学可验证**：程序穷举六连方（35 种自由六连方）并逐一验证可折叠性，得到**恰好 11 种**立方体展开图（1-4-1 型 6 种、2-3-1 型 3 种、3-3 型 1 种、2-2-2 型 1 种），与数学定理完全一致。
- **答案由模型生成**：不是"写题"，是"算题"，从根上避免错题。
- **种子化生成**：`mulberry32` + 字符串哈希，同一 seed 永远出同一题，便于复盘与分享。
- **PWA 离线**：装到桌面后断网也能练。

## 九、使用建议（每天 20–30 分钟就够）

1. **前 3 天**：只做「技巧」页第 1–2 阶段，把相对面排除、箭头法、时针法读到能默背口诀；配合实验室把 11 种展开图各折一遍。
2. **第 4–10 天**：每天「快速练习」20 题 + 复习队列；错题当天重做一遍并写一句错因。
3. **之后**：看「错题」页的薄弱方法，针对性做「就练这类」，直到该题型 30 天正确率 > 80%。
4. **考前一周**：只刷复习队列与错题本，不再学新方法。

## 十、说明

- **题目来源**：本应用内置的是**按考纲考点与经典方法自建的几何生成引擎**，可无限生成与真题同考点、同难度、同套路的新题；示例题目包为演示订阅机制用。真题因版权原因不内置，请以官方出版的历年真题卷为补充，用「手动录入 / JSON 导入」加入本应用一起练。
- **隐私**：所有数据只存在你自己的浏览器 `localStorage` 中，不上传任何服务器；订阅源同步仅由你的设备向指定 URL 发起只读请求。
